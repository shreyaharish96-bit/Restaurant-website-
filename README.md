# Restaurant Menu Website 🍽️

A simple static restaurant menu website built using HTML and CSS.

## Features
- Clean layout using CSS Grid and Flexbox
- Menu categories: Starters, Main Course, Beverages
- About Us and Contact Us sections
- Footer with copyright information

## Technologies Used
- HTML5
- CSS3

## Note
This project is currently optimized for desktop view.
Responsive design will be added in future updates.
